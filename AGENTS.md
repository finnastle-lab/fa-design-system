# Brand asset implementation

Use assets/fa-sunmark-dark.svg (black artwork for light backgrounds) and assets/fa-sunmark-light.svg (white artwork for dark backgrounds) as the canonical FA sunmark. Read README.md for usage and favicon guidance. Preserve the supplied SVGs exactly. Do not recreate the mark using text, CSS, generated artwork or alternate paths. These originals supersede differing sunmark examples in the older index.html reference. Copy the originals into consuming applications and preserve their aspect ratio.
